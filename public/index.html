A bit about me.

I'm Ye Kai, a 24-year-old third-year Software Engineering student at SIT. Right now I'm working on a tenant billing system for the SIT × SP Group microgrid. What keeps me going is seeing something I built get used, whether by me or by the people it was made for. When I'm not coding, I speedcube (Rubik's cube), play badminton amongst other sports, and love to edit videos.

Bench

One local app for file and media chores that usually take a different website each: about 70 tools (PDF, media, transcription, files) and an assistant that turns a plain-English request into a chain of tools. Files never leave the machine.

  • Python
  • FastAPI
  • Ollama
  • LLM tool calling
  • Whisper

One @tool declaration with typed parameters generates the GUI form, the REST endpoint and the LLM function-calling schema, so adding a tool never touches the UI, API or job runner.

  • "Ask Bench": a local Qwen 2.5 3B model plans chains of up to 4 tools, fills in their parameters and reads the results back, in 0.2 to 0.5 s per answer.
  • Hard safety rails: the model can't tick "book" or "apply" switches, never fills file fields from model text, and only creates new files. Falls back to keyword routing when no model is running.
  • Job lanes with cancellation and chaining, a permanent history of every run, a sealed mode that blocks access outside its folder, and passcode-protected phone access.
  • 465 automated integration and headless-browser checks.

File Manager

An Android file manager built around one rule: never lose a file. A move that fails halfway can't leave a broken copy, deletes can be undone, and the app has no network access at all.

  • Java
  • Android SDK
  • Material 3
  • Media3 ExoPlayer
  • Moves are renames where possible. Otherwise: copy to a hidden temp file, verify, fsync, rename, and only then delete the source.
  • A recycle bin with undo; nothing is overwritten without an explicit Replace.
  • No I/O on the main thread: one worker for every change, and a thumbnail pool that favours visible rows.
  • Duplicate and empty-folder finders, batch rename, zip, and image, text, PDF and video viewers.

Clip-to-Shorts pipeline

Turning a movie clip into a short by hand means writing a script, recording a voice-over, captioning and reframing it to vertical. This pipeline does all of it in one command: ML models analyse the footage and audio, and ffmpeg does the editing.

  • Python
  • ffmpeg

Signed steganography

Plain steganography hides data but can't tell you whether someone changed it. This tool hides a digitally signed payload in images, audio and video, so the receiver can check where it came from and catch tampering.

  • Python
  • Qt (PySide6)
  • NumPy
  • Digital signatures
  • 1 to 8-bit LSB embedding from a keyed, non-fixed start position, in images, WAV audio and lossless video.
  • Verification with Ed25519 and SHA-256 reports Authentic, Tampered or Signature Invalid, with replay protection.
  • My part: the attack lab and robustness layer (compression, cropping, noise, tampering) and the evidence test suite.

Phishing email detector

Paste in a suspicious email and get one verdict. A machine-learning model reads the body, while the sender, links and attachments are checked against threat-intelligence services.

  • Python
  • Flask
  • scikit-learn
  • VirusTotal API
  • A Multinomial Naive Bayes classifier trained on 33,268 emails from the Enron spam dataset, checked with a confusion matrix and ROC/AUC.
  • Sender addresses verified with Hunter.io; links and attachments submitted to VirusTotal and polled until the scan finishes.

  • My part: the Flask app, the Hunter.io and VirusTotal integrations, file uploads, scan history and the scoring that combines the checks.
