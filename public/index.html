01 · About

I like getting separate systems to work together.

Most of what I build connects real things: energy meters to a billing database, a local LLM to a set of tools, a marketplace to a Telegram digest. The interesting part is rarely the happy path. It's what happens when a file can't be decrypted, a model is down, or a scheduler starts twice.

I use AI coding agents to move faster, but I write the spec, review every change, and test on real devices and data. I care about software that fails safely and code that's easy to read.

AI · Desktop app2026

Bench

A local workbench with about 70 tools (PDF, media, transcription, files) and an assistant that turns plain-English requests into tool chains.

  • Python
  • FastAPI
  • JavaScript
  • SQLite
  • Ollama

One @tool declaration with typed parameters generates the GUI form, the REST endpoint and the LLM function-calling schema, so adding a tool never touches the UI, API or job runner.

  • "Ask Bench": a local Qwen 2.5 3B model plans chains of up to 4 tools, fills parameters and reads results back, in 0.2 to 0.5 s per answer. 40 of 40 on a routing eval.
  • Hard safety rails: the model can't tick "book" or "apply" switches, never fills file fields from model text, and only creates new files. Falls back to keyword routing when no model is running.
  • Job lanes with cancellation and chaining, SQLite history with a permanent archive, a sealed mode, and passcode-protected phone access.
  • 465 automated integration and headless-browser checks.

AI · Automation2026

CarouWatcher

Watches Carousell for listings I want. A quick AI pass screens results, a second reads each full listing against my notes, and matches arrive as one Telegram digest.

  • Python
  • Selenium
  • Gemini API
  • SQLite
  • Two-stage Gemini filtering: a lenient screen over the search grid, then a strict judge over each full page.

Video · ML2026

Clip-to-Shorts pipeline

Cuts a raw movie clip into a narrated, captioned vertical short in one command. ML models analyse the footage and audio; ffmpeg does the editing.

  • Python
  • ffmpeg
  • Whisper
  • Gemini
  • Scene detection and keyframes with ffmpeg. Whisper large-v3 transcribes dialogue and an AudioSet model tags sound effects.
  • Gemini writes the script from a contact sheet and Wikipedia research. Output outside 70 to 160 words is rejected and retried on the next model.
  • Kokoro text-to-speech for narration, with karaoke-style captions.
  • YOLOS person detection picks each 9:16 crop; one GPU-encoded ffmpeg pass cuts, crops, burns captions and mixes audio.
