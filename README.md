# yk-site

Personal portfolio of Tan Ye Kai. Plain HTML/CSS and a little vanilla JS, no build step.

- Site source: `public/`
- Deploy: every push to `main` publishes `public/` to GitHub Pages via `.github/workflows/deploy.yml`.
- Live: https://tyklol.github.io/yk-site/

## Run locally

```bash
cd public
python -m http.server 8000
# open http://localhost:8000
```
